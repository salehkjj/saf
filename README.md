# صَفّ | SAF

واجهة عربية بسيطة لتنظيم اليوم والمهام، بتصميم RTL داكن.

## المشروع
- تنظيم اليوم والمهام في واجهة عربية
- تصميم متجاوب يدعم الجوال
- HTML وCSS وJavaScript

## التشغيل
افتح ملف [`index.html`](./index.html) في المتصفح لعرض المشروع.

## ملاحظات
كود الواجهة موجود في `index.html`. ملف `README.md` مخصص الآن للتعريف بالمشروع فقط.
